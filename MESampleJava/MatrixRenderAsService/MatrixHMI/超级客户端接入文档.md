# Matrix-1.0.x 客户端（带管理功能）接入文档

## 1. 项目概述

本工程 `appSampleSuperClient` 是一个Android平台的Matrix-1.0.x超级客户端示例，演示如何通过Super Client能力与Matrix服务进程协同，构建多视口/多终端的高级控制端。

## 4. 集成流程

### 4.1 引入SDK依赖

将Matrix官方提供的SDK组件（AAR文件）放入`app/libs`目录，然后在`app/build.gradle`中配置依赖：

```gradle
dependencies {
    // ...其他依赖
    // 添加本地libs目录下的JAR和AAR文件作为依赖
    implementation(fileTree("libs") {
        include("*.aar")
    })
}
```

### 4.2 配置Application

创建或修改自定义Application类，实现Super Client引擎的初始化：

```java
public class MatrixDemoApp extends Application {
    private static final int BASE_CONNECTION_ID = 8000002;
    private IEngineSuperClient engine;
    private static MatrixDemoApp instance;

    @Override
    public void onCreate() {
        super.onCreate();
        instance = this;
        initEngine();
    }

    public static MatrixDemoApp getInstance() {
        return instance;
    }

    public void initEngine() {
        if (engine != null) {
            return;
        }
        engine = MatrixEngineSuperClient.newBuilder(this)
                .withServicePackageName("com.ns.sample.integrated")  // Matrix服务包名
                .withServiceConnectionId(BASE_CONNECTION_ID)         // 唯一连接ID
                .withEngineClientListener(new IEngineSuperClientListener() {
                    @Override
                    public void onStarted(boolean isSuccess) {
                        Log.i("---MatrixEngineSuperClient---", "onStarted success=" + isSuccess);
                    }

                    @Override
                    public void onBoundToService(boolean isSuccess) {
                        Log.i("---MatrixEngineSuperClient---", "onBoundToService success=" + isSuccess);
                    }

                    @Override
                    public void onUnboundToService() {
                        Log.i("---MatrixEngineSuperClient---", "onUnboundToService");
                    }
                })
                .build();
        engine.start();
    }

    public IEngineClient getEngineClient() {
        initEngine();
        return engine;
    }
}
```

在`AndroidManifest.xml`中注册该Application：

```xml
<application
    android:name=".MatrixDemoApp"
    <!-- ...其他配置 -->
>
    <!-- ...活动和服务配置 -->
</application>
```

### 4.3 界面集成与Surface管理

在Activity中初始化Surface并与Super Client引擎关联：

1. 布局文件中添加SurfaceView：

```xml
<SurfaceView
    android:id="@+id/surfaceView"
    android:layout_width="match_parent"
    android:layout_height="match_parent" />
```

2. Activity中初始化和管理Surface：

```java
public class MainActivity extends AppCompatActivity {
    private ISurface surface;
    private IEngineClient engineClient;
    private int cameraId = 0;
    private SurfaceView surfaceView;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        initMatrixSurface();
    }

    private void initMatrixSurface() {
        // 获取Super Client实例
        engineClient = MatrixDemoApp.getInstance().getEngineClient();
        surfaceView = findViewById(R.id.surfaceView);
        
        // 创建Surface
        surface = MatrixSurface.newBuilder(this, surfaceView)
                .withCameraId(cameraId)
                .withTouchSupport(true)
                .withAlphaValue(1.0f)
                .build();
    }

    @Override
    protected void onResume() {
        super.onResume();
        if (surface != null && engineClient != null) {
            // 关联Surface到引擎
            engineClient.attachSurface(surface);
        }
    }

    @Override
    protected void onPause() {
        super.onPause();
        if (engineClient != null && surface != null) {
            // 解除Surface关联
            engineClient.detachSurface(surface);
        }
    }
}
```

## 5. 核心功能解析

### 5.1 Super Client引擎初始化

通过`MatrixEngineSuperClient.newBuilder()`构建Super Client实例，主要参数包括：
- `withServicePackageName()`：指定Matrix服务的包名
- `withServiceConnectionId()`：指定唯一连接ID（用于多客户端场景）
- `withEngineClientListener()`：设置生命周期监听回调

### 5.2 Surface管理

- `MatrixSurface.newBuilder()`：创建Surface实例，关联到SurfaceView
- `engineClient.attachSurface(surface)`：将Surface关联到引擎，开始渲染
- `engineClient.detachSurface(surface)`：解除Surface关联，停止渲染
- `surface.setCameraId(cameraId)`：设置Surface关联的相机ID（默认0）
- `surface.setAsPrimarySurface()`：将Surface设为主视口（默认第一个Surface）
- `surface.enableTouch()`：启用Surface触摸事件（默认禁用）
- `surface.disableTouch()`：禁用Surface触摸事件
- `surface.setAlpha(alpha)`：设置Surface透明度（0.0-1.0），0.0为全透明，其它值为不透明
- `surface.resize(width, height)`：调整Surface大小，参数为新的宽度和高度（单位：px）

### 5.3 生命周期管理

- `onStarted(boolean)`：Super Client启动完成回调
- `onBoundToService(boolean)`：与Matrix服务绑定完成回调
- `onUnboundToService()`：与Matrix服务解除绑定回调

## 6. 调试建议

1. 查看Super Client相关日志：
   ```bash
   adb logcat | grep MatrixEngineSuperClient
   ```

2. 常见问题排查：
   - 如果`onStarted(false)`回调返回失败，请确认Matrix服务是否已在前台运行
   - 如果`onBoundToService(false)`回调返回失败，请检查服务包名是否正确，以及是否在AndroidManifest.xml中声明了queries
   - 确保应用具有必要的权限（如外部存储、前台服务通知等）

## 7. 注意事项

1. Super Client与普通Client可以并存，但需确保`connectionId`唯一，避免Binder连接冲突
2. 在退出或切换账户场景，可调用`engine.stop()`或`engine.unbindFromService()`释放资源
3. 多视口场景下，每个视口需要创建独立的Surface实例
4. 确保Matrix服务进程始终保持前台运行状态

## 8. 扩展功能

Super Client相比普通Client提供了更多高级能力：
- 会话管理：通过`start()`控制完整生命周期，可在一个会话中管理多个视口/命令
- 高级回调：`onStarted`回调提供服务端启动状态，便于在业务层做兜底处理
- 复合命令：可扩展到多终端控制、批量渲染指令或脚本执行
