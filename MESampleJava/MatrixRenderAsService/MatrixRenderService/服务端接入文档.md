# Matrix SDK AAR 接入文档

## 1. 项目概述

Matrix SDK 是一个基于 Matrix 引擎的 Android 服务组件，提供高性能的多视口渲染能力。本文档将指导您如何将 Matrix SDK 的 AAR 文件集成到您的 Android 项目中。

## 2. 环境准备

### 2.1 开发环境

- **Android Studio**：推荐使用 Ladybug+ 版本
- **Gradle Plugin**：8.5+
- **JDK**：17
- **Android SDK**：
  - compileSdk：36
  - targetSdk：36
  - minSdk：30


## 3. 集成步骤

### 3.1 导入 AAR 文件

1. 将 `MatrixSdk_SimpleService_1.0.1.aar` 文件复制到您项目的 `app/libs` 目录下

2. 在模块级 `build.gradle` 文件中添加依赖：

```groovy
dependencies {
    // 添加本地 AAR 依赖
    implementation(fileTree("libs") {
        include("*.aar")
    })
}
```

### 3.2 配置 Application 类

1. 创建或修改您的 Application 类，继承自 `android.app.Application`

2. 在 `onCreate()` 方法中初始化 Matrix SDK 并启动服务：

```java
import android.app.Application;
import android.content.Intent;
import android.util.Log;
import com.ns.matrix.PCKManager;
import com.ns.matrix.MatrixService;
import java.io.File;

public class YourApplication extends Application {
    private static final String TAG = "MatrixServiceApp";
    
    @Override
    public void onCreate() {
        super.onCreate();
        Log.i(TAG, "MatrixServiceApp created");
        initializePckWithSmartLoading();
        startMatrixServiceFromForeground();
    }
    
    // 负责从外部存储路径加载并部署 Matrix 资产（PCK/OBB）
    private void initializePckWithSmartLoading() {
        File externalDir = getExternalFilesDir(null);
        if (externalDir == null) {
            return;
        }
        String externalPath = new File(externalDir, "game.obb").getAbsolutePath();
        PCKManager.INSTANCE.smartInstallPckFromAssets(this, externalPath);
    }
    
    // 以前台服务形式启动 MatrixService
    private void startMatrixServiceFromForeground() {
        try {
            Intent intent = new Intent(this, MatrixService.class);
            startForegroundService(intent);
            Log.i(TAG, "Requested MatrixService start");
        } catch (Exception e) {
            Log.w(TAG, "Failed to start MatrixService", e);
        }
    }
}
```

3. 在 `AndroidManifest.xml` 中注册您的 Application 类：

```xml
<application
    android:name=".YourApplication"
    ...>
    <!-- 其他配置 -->
</application>
```

### 3.3 配置资源文件

1. 将 `game.pck` 文件复制到您项目的 `app/src/main/assets` 目录下

2. 将对应的so文件（如demo中的 `libMatrixMultiViewTemplate.android.template_release.arm64.so` ）复制到 `app/src/main/jniLibs/arm64-v8a` 目录下

## 4. 配置说明

在模块级 `build.gradle` 文件中，确保您的配置与以下设置一致：

```groovy
android {
    compileSdk {
        version = release(36)
    }
    
    defaultConfig {
        minSdk 30
        targetSdk 36
        // 其他配置
    }
    
    sourceSets {
        main {
            jniLibs.srcDirs = ['jniLibs']
        }
    }
    
    compileOptions {
        sourceCompatibility JavaVersion.VERSION_17
        targetCompatibility JavaVersion.VERSION_17
    }
}
```
